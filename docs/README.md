# Dokumentasjonen

Det som er likt for alle kunder, og som skillene i pluginene leser. Kunder og partnere kan lese det her.

| Mappe | Hva |
|---|---|
| [`monstre/`](monstre) | Mønstrene for god konfig i Neo: grunnreglene, og reglene per flate med beslutningstabellene |
| [`integrasjoner/`](integrasjoner) | Hvordan hvert system settes opp for Neo: hva kunden gjør, hva som legges i hvelvet, og hva forvalteren gjør |

Status for én kunde står ikke her, men i kundens eget repo.
