# ki

KI-oppsettet i Neo per sakstype: modellen, verktøyene og feltene med KI. Leser siste snapshot fra `forvaltning`, og
endringer går gjennom `/forvaltning:plan`.

| Skill | Hva |
|---|---|
| `ki:ki` | Oversikten per sakstype, og en endring gjennom planen |
| `ki:env` | Config-fila slik pluginen leser den |
