# helse

Helsa til oppsettet i Neo, gjennom Neo sin MCP-server. Bare lesing.

| Skill | Hva |
|---|---|
| `helse:helse` | Flytene og kjøringene i et tidsvindu: kort oversikt, «detaljer» gir alt |
| `helse:feilsok` | Én kjøring: hvilket steg, hvorfor, oppsett, data eller produkt |
| `helse:env` | Config-fila slik pluginen leser den |

`scripts/summarize-runs.mjs` teller kjøringene per flyt i vinduet, uten avhengigheter.
